# Captured edits

Legato records settled edits to completed dictations locally on iPhone and Mac. Open **History → Captured edits** on iPhone or **Captured edits…** in the Mac menu. Expand a record to inspect the original transcription, inserted text, before/after text, device locale and observation source. Delete individual records there; deletion is separate from dictation History. The view refreshes while open and displays the newest 200 records.

Capture follows a uniquely identifiable delivered scope in the same readable field for up to ten minutes. A one-second pause groups backspacing and replacement typing into one edit. Word-level summaries accompany exact before/after text, so sentence and formatting changes remain available for later analysis. Records identify the source dictation run or line; that identity is not always a History entry UUID.

The iPhone adapter observes settled field snapshots while the Legato keyboard is visible. After a Mac composer insertion is confirmed by reading the destination, Legato observes that same focused, readable Accessibility field. Legato's own writes suspend or reset observation; cursor movement alone produces no correction. A blank or newline-only field closes the observation. If Legato already saw the replacement, it can retain that edit even when the clear arrives during the one-second settling period. A clear adds no vote and cannot establish whether the host actually sent the message. Secure and unreadable fields are excluded.

Coverage is conservative: changing fields, losing readability, ambiguous repeated text, changed surrounding anchors, or a shifted/truncated iPhone proxy window can stop capture. Capture resumes after Legato's own writes settle. Unconfirmed insertions and unreadable fields supply no edit evidence. Keyboard-origin means observed after Legato keyboard input; either observation source may include host autocorrect. The recorded locale is the device locale, not detected speech language.

Each captured edit is a private JSON file under `Corrections/` in the app's data root (shared App Group on iPhone). The **Automatic vocabulary** section groups evidence by intended spelling and device locale. Two independent dictations corrected from “schemas” and “Canvas” to “Kemas” can teach one spelling. One observed correction from “Patrice” to “Badhri” stays available for corroboration. Spelling evidence from typing and suggestion choices comes from the Legato keyboard. The keyboard can use a deliberate choice in suggestions before a spelling qualifies as a recognizer hint.

Open an entry to inspect its evidence, edit its spelling, or dismiss it. Dismissal persists if the same term recurs. Style preferences still have explicit review. The personalization switch controls use of these preferences. Manual vocabulary pins remain available. Deleting a supporting observation or undoing a tracked edit can withdraw a spelling that loses the evidence it needed.

Recognition providers can receive qualified spellings as terms with the next request. Cleanup and Magic can receive relevant spellings and approved examples. Learning uses local rules. An automatically learned name does not make an ordinary word such as “schemas” an instruction to replace it.

## Optional future local training

A preference can improve the next request through a vocabulary hint or a cleanup example. Training a local model would be a separate opt-in feature. A captured edit contains text. Speech-model adaptation would also require the speaker's permission to retain the matching audio and an alignment between the audio and the verified transcript. Collect that permission before retaining audio and allow withdrawal and deletion. For cleanup adaptation, retain only reviewed source and target text that the user explicitly includes.

Before a training run, reserve complete dictation sessions for evaluation so that variants of the same utterance cannot appear in both training and evaluation. Compare the candidate with the current model on corrected names, style choices, unchanged passages and both German and English. Record regressions as well as gains. Keep the current model available, activate the candidate only after review, and allow immediate rollback. Removing source material must also retire any adapted model derived from it or rebuild it from the remaining authorized material.

# Shared speech classifier evidence

The #291 consolidation compared the two classifiers from `568efe8` before extraction. Input came from the two recorded November 11 Edge sequences preserved in `MacFieldQueueStressTests`: `theFirstKeyOnAnEmptyLastLineIsTypedOnce` (journal lines 691–705, seven snapshots) and `aTakeWhoseElementWasRecreatedTypesAtTheCaret` (journal lines 2087–2130, 23 snapshots). Each snapshot was supplied in order with speech active. Both original classifiers produced identical delivered text at all 30 snapshots. This is recorded-snapshot replay, not microphone or host-runtime acceptance; it does not establish parity on arbitrary speech.

`SpeechDelivery` now owns bounded word alignment, revised-word aliases and delivered-frontier tracking for both queues. The earlier keyboard implementation supplies the shared algorithm because it handles revised trailing words after user input freezes previously delivered text. Alignment considers at most the last 160 delivered words and 160 additional candidate words, preserving its existing bound.

One explicit policy difference remains. The existing `aRevisedFrontierEndingStillPinsNewSpeechByItsWords` contract changes “we left the harbour at dawn” to “We left the harbor at noon and”. The Mac keeps the whole revision deferred; keyboard delivery can align the revised last word and append the new speech. The shared classifier therefore accepts `allowsRevisedTail`: false in the Mac scheduling adapter, true for the keyboard. This preserves pre-consolidation behavior. The Mac adapter releases its authoritative target at stop; keyboard revision release remains governed by its existing verified near-caret/user-edit rules. Changing those policies belongs to the later pause/jump work.

`SpanPlanner` owns span grouping and pacing; `KeystrokePlanner` is a Mac execution adapter with platform key and movement costs. Neither cost model can broaden an edit across unchanged characters. `FieldInsertion` owns leading and trailing word boundaries. A Mac region retains the following character captured when it starts and recomputes its own trailing separator as the region's target changes, keeping existing host text out of the dictated region. Queue undo includes that separator, so undo restores the original surrounding text.
